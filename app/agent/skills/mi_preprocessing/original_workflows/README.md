# 两种本地模型的原始工作流契约

`dwdanet.json`和`dwtnet.json`分别对应`dwdanet-original-v1`与`dwtnet-original-v1`。它们记录经源码核对的数据输入、分割、训练归一化与推理边界，不是新的权重或任意脚本执行入口。

两者对BCI IV 2a/2b共享同一GDF提示后四秒处理：250Hz、1000点、排除真实EOG、保留原参考和顺序，不加软件带通/CAR。SHU输入已经由作者去坏段、去基线、0.5–40Hz FIR和切段；专用模块只整理五个会话，不能将其重构或宣称为连续原件。

SHU原训练MAT按作者同数据集channels.tsv关联单位uV，保留源数值导出train/test MAT；用于统一数值样本的版本显式uV→V。MAT自身无单位字段，不能凭幅值猜测。未来C模型适配器必须处理原训练单位与冻结归一化统计的一致性。

当前C01/C02已逐值核对为session1–4训练、session5测试；其余被试及历史checkpoint的划分没有全量验证。另一个no_cross_session脚本实际上将五会话混合后分层70/30，不能将名称当成隔离session的证据。

两家默认DG源码的全源池float32单标量mean/std(+1e-8)实现AST完全相同。LOSO源被试T+E参与源池；留出目标不参与归一化拟合，但其信号参与域适应、test_acc参与选checkpoint。现有2a清单使用从当前源池以float64流式重建的统计，不等于找回原训练精确统计。原流程预处理不重新fit源池，模型适配器只应用一次正确冻结统计。

DWTNet的DWT是原训练增强，不是推理前必须执行的去噪步骤。B/C存在旧权重候选不表示已确认其架构、归一化和划分来源；本契约不安装、不注册这些权重，也不让22通道权重接3/32通道数据。

所有source证据保存完整SHA256和原始行号；notebook定位指code cell 0的行号。原训练工作目录没有留档，旧相对路径/失效D盘路径不被伪装成当前有效配置。
